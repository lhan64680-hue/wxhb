# 待测试

- [修复] 本地启动脚本现在会同时检查主页和 `/canvas`，并主动等待画布路由完成 Next.js 首次编译后才返回成功或打开浏览器。已复现旧流程的 `/canvas` 冷编译超时并验证等待编译后返回 200；请停止后重新双击 `start-infinite-canvas.cmd`，确认启动后直接进入“我的画布”不会再出现打不开或长时间空白。

- [优化] 首页莫比乌斯创作轨道的两端弯曲和中部交叉改为连续切线，前景环带拥有完整的侧面、边缘高光与阴影，不会出现断裂或尖锐转折；悬停工具球时渐变、流光与浮动仍会暂停。请在日光和夜间主题下进入首页，观察轨道运行一圈，并分别悬停五个工具球确认曲线、叠层与工具说明正常。

- [修复] 视频创作台与无限画布现在都默认使用 Kimi K3 优化本地 H3 提示词。视频创作台会在创建任务前按模型、首尾帧、图片/视频/音频参考自动选择 Base 或 Ref2VA 模板，并把优化后的提示词保存到生成历史。请在 Kimi Key 已保存时分别从画布和视频创作台提交一次 H3，确认两处均提示“H3 提示词已由 Kimi K3 按官方规则优化”。

- [修复] H3 默认使用的 Kimi K3 提示词优化不再传入接口拒绝的 `temperature=0.2`，而是固定为该模型要求的 `temperature=1`。已通过 TypeScript 检查和生产构建；请在“配置 → 本地模型渠道”保存 Kimi K3 Key 后发起一次 H3 视频，确认提交前提示“H3 提示词已由 Kimi K3 按官方规则优化”，而非“已改用 H3 合规模板”。

- [修复] GRS 图片任务的 `/draw/result` 轮询请求只包含任务 ID，本地中继不再错误要求 `model` 字段；本地直连任务也不会再被云端恢复轮询覆盖。运行中的浏览器本地任务即使进度先到 100% 但图片结果尚未返回，也会继续等待结果，不会被画布状态检查误判为失败；只有刷新页面后无法恢复的遗留本地任务才会改为可重试错误。中继还会绕过系统 DNS 被代理/TUN 映射至 `198.18.0.0/15` 的虚拟地址，通过固定 IP 引导的公开 DNS 直连 GRS 公网地址。已通过结果请求无 `model` 回归、虚拟 DNS 地址过滤回归、实际 GRS 无效 Key 直连响应、TypeScript 检查和生产构建；请用已保存的 GRS Key 各发起一次文生图和图生图，确认成图直接显示，或在异常时 120 秒内显示具体失败原因而非无限等待。

- [修复] GitHub 自动发布不再依赖会在 Windows Codex 环境崩溃的 Git 凭据助手。发布脚本会仅在进程内读取 GitHub CLI 授权、清除代理环境变量、用临时授权头推送，随后立即清理；Token 不会写入项目文件或 Git 配置。已完成一次只读远端 `main` 验证；下一次版本发布应不再弹出 `git-remote-https.exe` 内存读取错误框。

- [修复] GRS AI `gpt-image-2` 的文生图与图生图不再由浏览器跨域直连，而是经本机受限中继直接访问国内 GRS；中继仅允许本机请求和固定的 GRS 域名，外部请求显式不使用代理。已通过 Go handler/router 测试和前端 TypeScript 检查；请在“配置 → 本地模型渠道”确认 GRS Key 已保存后，分别用纯文本和一张本地参考图各生成一次，确认不会出现 Network Error，失败时应直接显示上游错误。

- [新增] 本地 MiniMax-H3 在每次视频提交前会使用已配置的 Kimi K3 将“原始提示词 + 首尾帧/参考图”转换为官方 H3 结构化提示词：文字/首尾帧模式使用 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`，全能参考使用固定六段。视频节点会保存原提示词、优化后提示词和降级原因；未配置或调用失败会显示提示并继续使用本地合规模板。请用一张图片连接 H3 视频节点，填写明确动作和镜头提示词后生成，确认弹出“Kimi K3 按官方规则优化”且成片遵从动作；再临时移除 Kimi Key 验证仍能提交 H3。

- [修复] 外部图片参考源若已删除、过期或无法访问，画布不会再弹出 Runtime Error。存在其他可用参考图时会提示“已跳过 N 张失效参考图”并继续生成；全部普通参考图失效、或明确选中的首尾帧失效时会提示重新上传替换。已对原始 `502` 参考图 URL 复现并完成画布页与 TypeScript 验证；请用一张失效图和一张正常图分别连接到视频节点确认提示与生成行为。

- [新增] H3 本地视频任务在生成期间会显示 1–95% 的预估进度，完成时显示 100%。视频设置窗口中的模式选择改为“标准生成 / 多参考 Ref2VA / 4 步 Turbo”三张卡片，并展示对应的速度和参考能力说明。已用 5 秒、864×480 的 Turbo 任务验证：创建后接口返回 1%，本机完成耗时 155.85 秒且 MP4 可读取；请从画布发起一次 H3 任务，确认节点进度条会随轮询递增、模式卡片能正确切换。

- [新增] H3 视频节点的“视频设置 → H3 运行模式”现在提供“标准 / 多参考 / 4 步 Turbo”。标准采用 20 步；多参考会切换到 Ref2VA 并可选择图片、视频、音频素材；Turbo 采用本地 v4-600 LoRA 与 4 步双流采样，仅支持文生和首尾帧。已在本机完成一次 5 秒、864×480 Turbo 成片（159.71 秒）；请在你自己的提示词和素材下分别切换三种模式确认画面偏好与素材约束符合预期。
