# 待测试

- [调整] 首页重设计为莫比乌斯创作轨道：五个工具球沿渐变无穷环缓慢运动，环的渐变与高光持续流动；鼠标悬停或键盘聚焦工具球时全部动画暂停并显示说明，点击可进入对应工作台。首页左侧固定显示本机历史项目（项目名称、节点数、连线数），可直接进入项目或新建项目；日光与夜间主题均适配。
- [调整] 页面左上角的“无限画布”主页入口及桌面“无限画布工作台”快捷方式均使用新的圆角无限符号 Logo。
- [新增] 无限画布项目列表页顶部显示导航栏：可进入主页、生图工作台、视频创作台、提示词库和我的素材；具体项目的全屏画布编辑页仍不显示该导航，避免影响创作空间。移动端可从导航抽屉进入相同页面。
- [新增] 直接点击画布连接线后，连线中部会显示剪刀按钮；点击剪刀仅删除该条连接，不删除两端节点。节点关联高亮不会显示剪刀按钮。
- [调整] 本地开发页面已关闭 Next.js Dev Tools 悬浮指示器，左下角不应再出现英文调试按钮或其 Preferences 面板；编译和运行错误仍在终端日志中保留。
- [调整] 已取消前台账户登录/注册入口：访问 `/login` 会回到首页，顶部不再显示登录或账户菜单，旧登录状态会在启动时清除；画布、素材页和本地模型配置可直接使用。后端管理接口仍保留原有鉴权，不会因前台取消登录而向局域网开放。
- [调整] 顶部版本检查与 GitHub 图标已切换到 `lhan64680-hue/wxhb`；点击“版本更新”后，最新版本与更新日志应从该仓库读取，当前版本卡片可直接打开该仓库。
- [新增] 本地直连配置默认增加 “GRS AI GPT Image 2（国内直连）” 渠道，地址为 `https://grsai.dakka.com.cn`，默认生图模型为 `gpt-image-2`。图生图按 GRS 官方绘图端点发送参考图 `urls` Data URL 数组，创建任务后轮询结果；即使已登录也保持浏览器到国内节点直连。图片任务最长 120 秒且不重试，避免重复扣费；成功图片右下角会显示实际生成耗时。此前预置的空 OpenAI 渠道会自动替换，已有 OpenAI Key 不会迁移到 GRS。图片节点若失败会显示上游具体错误。MiniMax-H3 仍保持默认视频模型与本地渠道不变。
- [新增] MiniMax-H3 本地直连视频模型接入：默认视频模型为 `minimax-h3/text-to-video`，本地渠道为 `http://127.0.0.1:7860/v1/videos`。视频设置中的“全能参考”会自动切换到本地 `minimax-h3/reference-to-video` Ref2VA 模型；可从已连线节点选择最多 9 张图片、3 段视频、3 段音频（总计最多 12 个文件），并以 `<Picture 1>`、`<Video 1>`、`<Audio 1>` 在提示词中指代。Ref2VA 约 21 GB 权重已从 ModelScope 国内源直连下载，适配器健康检查与原生多模态条件节点已验证；仍待以用户自己的真实素材完成一次人工成片验收。首尾帧模式保持可用。
- [新增] 视频节点的“信息”面板会显示本次任务的“生成耗时”。该值由任务创建至完成或失败时冻结，和视频播放时长区分开来；对没有生成任务记录的上传视频不会错误显示。
- [新增] 新建文本节点默认使用 “Kimi K3（Moonshot 国内直连）”，地址预置为 `https://api.moonshot.cn/v1`、模型为 `kimi-k3`，不写入 Key；用户在“配置 → 本地模型渠道”填入 Moonshot API Key 后，配置会保存到本机后台，由本机后端直连国内 Kimi 接口，不经第三方代理且不把服务端 Key 暴露到浏览器请求。文本节点提供自由写作、文生视频提示词、图片反推提示词、文字生音乐提示词四种模式；已连线的图片和视频会作为 Kimi 的多模态内容传入。文字生音乐只生成音乐提示词，音频参考不会被伪装成 Kimi 可理解的输入。
- [修复] 画布启动时会在 `8188` 未运行时异步启动已验证的本地 H3 SageAttention 引擎，再恢复 `7860` 适配服务；不使用代理。启动参数固定包含 `--use-sage-attention`，输入、输出目录固定为画布运行目录的 `h3-input`、`h3-output`，避免受限引擎账户写入原 `C:` 文档目录时触发上传 500 或 MP4 保存 `Permission denied`。已通过真实 multipart 上传及 ComfyUI 输出写入探针验证目录可写；任务状态为 `failed` 时前端会展示错误而不再无限轮询。适配服务、引擎与画布可一并停止。
- [新增] 画布项目库和工作台已收敛为纯创作界面：项目页采用深色项目库，新建项目进入无限画布；双击空白处创建文本、图片、视频、音频或本地素材节点，节点两侧的连接点始终可见并可拖拽连线。画布页不再展示全站工具导航或高级节点创建入口。
